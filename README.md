# WP Image Fixer

Make slow WordPress pages load faster. WP Image Fixer lets Claude find the heaviest images on your WordPress site, shrink and resize them, and undo the changes if you don't like the result.

## Use it

1. Install the plugin, then connect WP Image Fixer using Claude's connection and authentication flow.
2. Ask Claude something like "my WordPress site is slow, can you shrink the images?" or "compress the images in my media library."
3. Claude inspects your images and describes proposed changes, using savings estimates only when the tools provide them. The included skill instructs Claude to obtain approval before applying changes.
4. After optimizing, you can request restoration where the service retains the original images. Availability and retention depend on the service.

## Data

This bundle contains instructions and a reference to the existing remote connector at https://mcp.wpimagefixer.com/mcp. Tool requests are handled by WP Image Fixer. Claude and WP Image Fixer handle connection and usage data under their respective policies; this bundle contains no separate storage service.
